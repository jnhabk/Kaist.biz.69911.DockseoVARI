# 독서 모임 플랫폼 서비스 WhyTree

- 이름 또는 별명: Jisu
- 작성일: 2026.10.28

## 표기 방법

- 상위 목적(Why) 아래에 이를 실현하는 방법(How)을 들여썼습니다. 화살표 방향은 아래의 How에서 위의 Why입니다.
- `[씨앗]`: 먼저 떠올린 다섯 가지 일. 슬라이드의 갈색 테두리 상자입니다.
- `[아직 하지 않는 일]`: 지금 하지 않지만 새로 찾은 일. 슬라이드의 점선 상자입니다.
- 별도 연결 표시가 없으면 실선 연결(가장 중요한 Why)이며, `[점선 연결]`은 바로 위 목적에 대한 부가적인 연결입니다. 상자 종류와 연결 종류는 별개입니다.
- 하나의 How가 여러 Why를 돕는 경우 각 목적 아래에 같은 노드를 반복했습니다. 반복 표기는 새 노드를 추가한 것이 아닙니다.
- 슬라이드에서 연결되지 않은 상위 목적 사이에는 임의로 연결을 추가하지 않았습니다.
