# 모임 지향점 설문 — 프로토타입

`docs/specs/jinha-feature.md`의 프로토타입. HTML 파일 하나로 되어 있다. 서버, 로그인, DB가 없다.

| 파일 | 하는 일 |
|-|-|
| `orientation-survey.html` | 가입 설문, 모임 집계, 정기 일정 투표·약속, 중간 가입자, 정기 재설문 화면과 규칙 전부 |

테스트 모임은 4명이다. 멤버 A·B·C는 샘플 응답이 미리 들어 있고, 나머지 1명(나)이 직접 응답한다. 샘플 응답과 책 이름은 테스트를 위해 지어낸 것이다.

## 인프라 설정

**필요 없다.** 설문 단계는 AI를 부르지 않아서 API 키를 숨길 서버가 필요 없다. 집계, 소수 취향 판정, 투표 규칙은 모두 페이지 안의 JavaScript가 계산한다. 응답은 브라우저 저장소(localStorage)에만 남고, 다른 사람이나 다른 컴퓨터와 공유되지 않는다. 그래서 Node.js 설치도, `.env`도 필요 없다.

나중에 실제 멤버 4명이 각자 폰에서 응답하게 하려면 응답을 모아 둘 서버나 DB가 필요하다. 이건 지원 님 프로토타입(`prototypes/jiwon/`)과 합칠 때 정한다.

## 여는 법

1. 파일 탐색기에서 `prototypes/jinha/orientation-survey.html`을 찾는다.
2. 더블클릭한다. Chrome이나 Edge에서 열린다.
3. 위쪽 "시연 컨트롤"의 버튼으로 시나리오를 바꾼다. 맨 오른쪽 "처음부터 (응답 지우기)"를 누르면 내 응답과 투표가 모두 지워진다.

## 정상 작동 확인 순서

처음 열었을 때나 "처음부터"를 누른 뒤, 아래 순서대로 해 보면 모든 규칙을 한 번씩 확인할 수 있다.

**① 새 모임 첫 설문**
1. 6장의 설문을 넘긴다. 3장에서 분량이나 난이도를 고르지 않고 "다음"을 누르면 빨간 안내가 나와야 한다.
2. 5장 "모임 시간"에서 칸을 누를 때마다 ○ 가능 → ★ 선호 → ✕ 불가로 바뀌어야 한다.
3. 6장 "마지막 확인"에 내 응답 요약이 나오고, "수정"을 누르면 해당 장으로 돌아가야 한다.
4. 제출하면 집계 화면이 "응답 4/4명"으로 열린다.

**집계와 투표 (①에 이어서)**
5. 장르 목록에 "다수 취향"(상위 3개)과 "소수 취향"(4명 중 1명 이상 선호) 표시가 붙는다.
6. 시간표에서 초록 테두리 칸이 투표 후보다. 불가(✕)가 있는 칸은 후보가 아니어야 한다.
7. 정기 일정, 진행 시간, 준비 완료 시점에서 각각 "동의"를 누르면 확정된다. 셋 다 확정되면 "이 시간 비워 두겠습니다" 버튼이 나오고, 누르면 "약속한 멤버 4/4명"이 된다.
8. "시연: 다른 멤버의 투표"를 **멤버 B가 정기 일정에 한 번 반대**로 바꾸고 다시 동의한다. "반대 1명"이 기록되고 재투표 1/2가 열려야 한다. 거기서 동의하면 전원 동의로 확정된다.
9. **계속 반대**로 바꾸고 세 번 동의한다. "이번 회차 모임장(멤버 A)이 정했어요"가 나와야 한다.
10. "처음부터"를 누르고 ①을 다시 하되, 5장에서 화·수·목 저녁과 토·일 오후를 모두 ✕로 만든다. 집계에서 "불가 1명인 칸까지 후보를 넓혔어요" 안내가 나오고, 투표 카드에 "이 시간에 맞춰 줄 수 있나요?"가 보여야 한다.

**② 두 번째 모임 가입**
11. 첫 화면에서 "기존 모임에 제출한 설문과 동일하게 적용할까요?"를 물어야 한다. "예"를 누르면 응답이 채워진 채 6/6 확인 화면으로 바로 가야 한다.

**③ 중간 가입자**
12. 설문을 마치면 "이 모임의 정기 시간을 비워 둘 수 있나요?" 화면이 나온다. 설문에서 목요일 저녁을 ✕로 했다면 그 사실을 알려줘야 한다.
13. "이 시간은 어렵습니다"를 누르면, 멤버 전원에게 이름 없이 가는 알림 미리보기와 "다음 재설문 안건" 문구가 나와야 한다.

**⑤ 정기 재설문**
14. 1장에서 준비 완료 시점을 고르지 않으면 넘어가지 않아야 한다. 지난 마감 때 내 기록(진도·밑줄·생각)이 보여야 한다.
15. 2장에서 "바꾸고 싶어요"를 고르면 가입 때 답이 채워진 시간표가 나와야 한다.
16. 3장에 가입 때 취향이 미리 채워져 있어야 한다.
17. 4장 "당신의 기존 취향과 다른 책 회차는 어떠셨나요?"는 내가 0점 이하로 답한 장르의 책이 지난 3권 중에 있을 때만 나와야 한다. 3권의 장르를 모두 +1 이상으로 답했다면 3장에서 끝나야 한다.
18. 제출 화면에 바뀐 취향(예: "SF·판타지 −1→+1")이 나와야 한다. 정기 시간 "변경"을 골랐다면 ④ 집계 화면에서 일정 투표가 다시 열려 있어야 한다.

## 알려진 한계

- 모임원이 4명이면 20% 기준이 1명이라, 한 명만 좋아해도 소수 취향 후보가 된다. 그래서 상위 3개 밖의 거의 모든 장르에 "소수 취향"이 붙을 수 있다. 규칙대로 동작하는 것이지만, 실제 모임에서 보기에 너무 많으면 기준을 다시 정해야 한다.
- 샘플 멤버의 투표는 각자 답한 가능 시간과 범위로 자동 결정된다. 불가로 답한 샘플 멤버에게 묻는 확인은 "맞춰 볼게요"로 가정한다.
- 알림은 실제로 보내지 않고 미리보기만 보여준다.
